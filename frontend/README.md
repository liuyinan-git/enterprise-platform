# 前端

技术栈：Vue 3 + TypeScript + Vite + Element Plus + ECharts + Vue Router + Pinia + Axios。

## 开发

```bash
npm install
npm run dev      # 开发服务器（默认 http://localhost:5173，/api、/health 已代理到后端 7553）
npm run build    # 生产构建
```

## 目录

- `src/api/`：后端接口客户端
- `src/layouts/`：布局
- `src/router/`：路由
- `src/views/`：页面
- `src/components/`：通用组件
- `src/stores/`：Pinia 状态
